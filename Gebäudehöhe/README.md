# Gebäudehöhe / Building height (LoD2)

**DE:** LoD2-CityGML-Kacheln (2 km × 2 km) der Bayerischen Vermessungsverwaltung hier ablegen, Dateiname `xxx_xxxx.gml` (z. B. `690_5334.gml`). Die Kacheln müssen das gesamte Untersuchungsgebiet abdecken. Download: <https://geodaten.bayern.de/opengeodata/OpenDataDetail.html?pn=lod2>

**EN:** Place the LoD2 CityGML tiles (2 km × 2 km) of the Bavarian surveying administration here, file name `xxx_xxxx.gml` (e.g. `690_5334.gml`). The tiles must cover the entire study area. Download: <https://geodaten.bayern.de/opengeodata/OpenDataDetail.html?pn=lod2>
