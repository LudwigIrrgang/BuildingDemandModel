# Wetterdaten / Weather data

**DE:** DWD-Testreferenzjahre (TRY 2015 und 2045) hier ablegen – ein Unterordner pro 1-km-Kachel, z. B. `TRY_481399115778/TRY2015_481399115778_Jahr.dat` (+ `_Somm`, `_Wint`, und dieselben Dateien für `TRY2045`). Download: <https://kunden.dwd.de/obt/index.jsp> → „Testreferenzjahre TRY“.

**EN:** Place the DWD test reference years (TRY 2015 and 2045) here – one sub-folder per 1 km tile, e.g. `TRY_481399115778/TRY2015_481399115778_Jahr.dat` (+ `_Somm`, `_Wint`, and the same files for `TRY2045`). Download: <https://kunden.dwd.de/obt/index.jsp> → "Testreferenzjahre TRY".
